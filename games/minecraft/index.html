      About

      What is Eaglercraft?

      Eaglercraft is a community port of Minecraft to plain JavaScript / WebAssembly so it runs in any modern browser — no Java, no installer.

      This launcher is a front-end. It catalogs the public client builds and launches them in an iframe (or a new tab) so you can switch versions and servers without bookmarking ten different URLs.
